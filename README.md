# BBC — BEAST Broadcasting Corporation

Updated parody website for the Tuks Rowing B Men / BEAST crew at Universities Boat Race on the Kowie River.

## Upload to GitHub
Replace the old site files in your GitHub repository with everything in this folder, including the new `images` folder. Keep the folder structure exactly as supplied. Commit the changes and GitHub Pages will republish automatically.
